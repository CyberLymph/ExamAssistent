### **Aufgabe 1: Fehlersuche**
#### **(a) Fehler: Groß-/Kleinschreibung von `True`**
- **Fehler:** `true` ist falsch geschrieben, es muss `True` (mit großem `T`) sein.
- **Begründung:** In Python sind boolesche Werte `True` und `False` Großbuchstaben.

#### **(b) Fehler: Längeninkonsistenz zwischen Listen**
- **Fehler:** `stadt` hat 4 Elemente, `einwohner` nur 3 → IndexError bei `stadt[3]`.
- **Begründung:** `for i in range(len(stadt))` läuft bis 3, aber `einwohner` hat nur 3 Einträge.

#### **(c) Fehler: Keine Basis für Rekursion**
- **Fehler:** Keine Abbruchbedingung für die Rekursion (`n <= 0` fehlt).
- **Begründung:** Unendliche Rekursion führt zu `RecursionError`.

#### **(d) Fehler: Uninitialisierte Variable `i`**
- **Fehler:** `i` ist nicht definiert, bevor es in `while i <= 10` verwendet wird.
- **Begründung:** Python erkennt uninitialisierte Variablen nicht automatisch.

#### **(e) Fehler: Division durch 0**
- **Fehler:** `int(b)` ergibt `0` → Division durch Null.
- **Begründung:** `b = 0.6` wird zu `0` bei `int(b)`.

### **Aufgabe 3: Run Length Encoding (RLE)**
#### **(a) `encode(text)`**
- **Lösung:**
  ```python
  def encode(text):
      result = []
      count = 1
      for i in range(1, len(text)):
          if text[i] == text[i-1] and count < 9:
              count += 1
          else:
              result.append(f"{count}{text[i-1]}")
              count = 1
      result.append(f"{count}{text[-1]}")
      return "".join(result)
  ```

#### **(b) `decode(text)`**
- **Lösung:**
  ```python
  def decode(text):
      result = []
      i = 0
      while i < len(text):
          if text[i].isdigit():
              count = int(text[i])
              result.append(text[i+1] * count)
              i += 2
          else:
              result.append(text[i])
              i += 1
      return "".join(result)
  ```

### **Aufgabe 4: Schimpfwortfilter**
#### **(a) `readSwearwordData(filename)`**
- **Lösung:**
  ```python
  def readSwearwordData(filename):
      try:
          with open(filename, "r") as file:
              return [[line.split()[0], int(line.split()[1])] for line in file]
      except:
          return []
  ```

#### **(b) `checkText(message, swearwords)`**
- **Lösung:**
  ```python
  def checkText(message, swearwords):
      total_severity = 0
      words = message.split()
      for i, word in enumerate(words):
          for [swear, severity] in swearwords:
              if word.lower() == swear.lower():
                  total_severity += severity
                  words[i] = "***"
      if total_severity > 7:
          return "Nachricht wurde gelöscht"
      return " ".join(words)
  ```

#### **(c) Hauptprogramm**
- **Lösung:**
  ```python
  print(checkText("Du bist natürlich kein Idiot", readSwearwordData("swearwords.txt")))
  ```
