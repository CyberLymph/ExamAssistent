### **Aufgabe 1: Fehlersuche**
**Ziel:** Fehler in Python-3-Programmen identifizieren und erklären.

#### (a) Fehler:
```python
1 bestanden = true  # Fehler: "true" muss "True" (Großschreibung) sein.
2 if bestanden:
3 print("Aufgabebestanden")
4 else:
5 print("Aufgabenicht bestanden")  # Fehler: Leerzeichen fehlt zwischen "Aufgabe" und "nicht".
```

#### (b) Fehler:
```python
1 stadt = ["Duisburg", "Essen", "Mülheim an der Ruhr", "Krefeld"]
2 einwohner = [495885, 582415, 170739]  # Fehler: Die Liste hat nur 3 Elemente, aber 4 Städte.
3 for i in range(len(stadt)):
4 print(stadt[i],"hat", einwohner[i],"Einwohner")  # IndexError bei der 4. Stadt.
```

#### (c) Fehler:
```python
1 def fakultaet(n):
2 return n * fakultaet(n - 1)  # Fehler: Keine Abbruchbedingung (unendliche Rekursion).
3 n=5
4 print("Fakultät =", fakultaet(n))
```

#### (d) Fehler:
```python
1 print("Countdown")
2 while i <= 10:  # Fehler: Variable "i" nicht definiert.
3 print("{10 - i}")  # Fehler: Formatierung falsch (f-String oder str() nötig).

```

#### (e) Fehler:
```python

2 b = 0.6
3 print(a / int(b))  # Fehler: Division durch 0 (int(0.6) = 0).
```

### **Aufgabe 3: Run Length Encoding (RLE)**
**Ziel:** RLE-Algorithmus implementieren und analysieren.

#### (a) `encode(text)`:
- Komprimiert Text mit RLE, aber maximal 9 aufeinanderfolgende Zeichen.
- Beispiel: `"AAAAAAAAAAABBBCDDDDD"` → `"9A2A3B1C5D"`.

#### (b) `decode(text)`:
- Dekomprimiert RLE-Text zurück in den Originaltext.

#### (c) Nachteile von RLE:
- **Ineffizient bei:** Texten mit vielen verschiedenen Zeichen (z. B. `"abcabcabc"` → `"1a1b1c1a1b1c1a1b1c"`).
- **Erhöht Speicherbedarf**, wenn die Komprimierung nicht lohnt.

#### (d) `checkRLE(text)`:
- Prüft, ob RLE sinnvoll ist (z. B. durch Vergleich der Längen von Original und komprimiertem Text).

### **Aufgabe 4: Schimpfwortfilter**
**Ziel:** Unangemessene Wörter in Texten ersetzen oder löschen.

#### (a) `readSwearwordData(filename)`:
- Liest eine Datei mit Schimpfwörtern und deren Schweregrad ein.
- Beispiel: `"Fuck 1"` → `['Fuck', 1]`.

#### (b) `checkText(message, swearwords)`:
- Ersetzt Schimpfwörter durch `***` (Groß-/Kleinschreibung ignorieren).
- Löscht Nachricht, wenn Summe der Schweregrade > 7.

#### (c) Hauptprogramm:
```python
print(checkText("Du bist natürlich kein Idiot", readSwearwordData("swearwords.txt")))
```

### **Aufgabe 5: Java-Klasse "Moebel"**
**Ziel:** Java-Klasse für Möbel mit Konstruktor und `toString()` erstellen.

#### Lösung:
```java
public class Moebel {
    private String name;
    private double preis;

    public Moebel(String name, double preis) {
        this.name = name;
        this.preis = preis;
    }

    @Override
    public String toString() {
        return name + " (" + preis + " €)";
    }

    public static void main(String[] args) {
        Moebel regal = new Moebel("Yllib", 40);
        System.out.println(regal);  // Ausgabe: "Yllib (40.0 €)"
    }
}
```
