  \"topic\": \"string\", \
  \"points_total\": integer, \
  \"question\": \"kurze klare Frage, max. 2 Sätze\", \
  \"options\": [ \
    {\"id\": \"A\", \"text\": \"Antwortoption\", \"correct\": true|false}, \
    {\"id\": \"B\", \"text\": \"Antwortoption\", \"correct\": true|false}, \
    {\"id\": \"C\", \"text\": \"Antwortoption\", \"correct\": true|false}, \
    {\"id\": \"D\", \"text\": \"Antwortoption\", \"correct\": true|false} \
  ], \
  \"explanation\": \"kurze 1-Satz-Erklärung für die richtige Antwort\" \
} \
Regeln: \
- Genau eine richtige Antwort (correct=true). \
- Keine langen Texte, keine Tabellen, kein Markdown. \
- Nur JSON zurückgeben, ohne zusätzliche Kommentare."
